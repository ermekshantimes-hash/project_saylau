# 🚀 Быстрый старт - Система выборов РК

## Автоматическая установка (рекомендуется)

### Шаг 1: Установка PostgreSQL

1. Скачайте PostgreSQL: https://www.postgresql.org/download/windows/
2. Установите с паролем для пользователя `postgres` (запомните пароль!)
3. PostgreSQL будет доступен на порту 5432

### Шаг 2: Настройка проекта

1. Откройте PowerShell или CMD в папке `C:\elections_rk`

2. Запустите установку:
```bash
setup.bat
```

Этот скрипт:
- Создаст виртуальное окружение Python
- Установит все зависимости
- Создаст необходимые папки
- Создаст файл .env

### Шаг 3: Настройка базы данных

1. Отредактируйте файл `.env`:
```
DATABASE_URL=postgresql://postgres:ВАШ_ПАРОЛЬ@localhost:5432/elections_rk
```
Замените `ВАШ_ПАРОЛЬ` на пароль PostgreSQL

2. Инициализируйте базу данных:
```bash
init_database.bat
```

Введите:
- Username: `postgres` (или ваш)
- Database name: `elections_rk` (или оставьте по умолчанию)

### Шаг 4: Запуск сервера

```bash
start_server.bat
```

Сервер запустится на http://localhost:8000

### Шаг 5: Открытие интерфейса

Откройте в браузере:

1. **Результаты выборов**: `C:\elections_rk\frontend\index.html`
2. **Просмотр участка**: `C:\elections_rk\frontend\precinct.html`
3. **Загрузка протокола**: `C:\elections_rk\frontend\upload.html`

## Проверка работы

1. Откройте http://localhost:8000/docs - должна открыться документация API
2. В браузере откройте `index.html` - должны загрузиться тестовые данные
3. Попробуйте загрузить протокол через `upload.html`

## Тестовые данные

После установки в системе будут доступны:

- **2 выборов**: Президентские 2024, Мажилис 2024
- **20 регионов**: РК + области + районы Алматы
- **4 участка** с результатами
- **6 кандидатов** для президентских выборов

Вы можете просмотреть их через веб-интерфейс!

## Решение проблем

### База данных не подключается

```powershell
# Проверьте, что PostgreSQL запущен
Get-Service -Name postgresql*

# Если не запущен, запустите
Start-Service postgresql-x64-14  # версия может отличаться
```

### Ошибка импорта модулей

```powershell
# Активируйте виртуальное окружение
.\venv\Scripts\Activate.ps1

# Переустановите зависимости
pip install -r requirements.txt
```

### Порт 8000 занят

Измените порт в `start_server.bat`:
```batch
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8001
```

И в HTML файлах измените `API_BASE`:
```javascript
const API_BASE = 'http://localhost:8001';
```
