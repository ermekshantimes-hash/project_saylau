## 🎨 Создать свой CSV файл

### Вариант 1: Excel/Google Sheets
1. Создайте таблицу с 3 колонками
2. Заполните: номер_участка, имя_кандидата, голоса
3. Сохраните как **CSV (UTF-8)**

### Вариант 2: Python скрипт

```python
import csv

data = [
    [1165, 'Касым-Жомарт Токаев', 1250],
    [1165, 'Марат Нурланов', 980],
    # добавьте больше...
]

with open('my_results.csv', 'w', encoding='utf-8', newline='') as f:
    writer = csv.writer(f)
    writer.writerow(['precinct_number', 'candidate_name', 'votes'])
    writer.writerows(data)
```

Затем загрузите:
```powershell
python upload_results.py my_results.csv
```

## ❓ Частые вопросы

**Q: Сколько участков я могу загрузить?**
A: До 12,000 (все участки в БД)

**Q: Что если участок уже есть?**

**Q: Какая кодировка?**
A: UTF-8 (обязательно!)

A: Запустите `start_server_8888.bat`
