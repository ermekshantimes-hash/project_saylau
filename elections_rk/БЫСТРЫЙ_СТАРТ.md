## 📄 КАК ЗАГРУЗИТЬ ПРОТОКОЛ

### Шаг 1: Откройте страницу
```
http://localhost:8000/upload.html
```

### Шаг 2: Заполните форму

1. **Выберите выборы** из списка (например: "Президентские выборы 2024")
2. **Введите ID участка**: просто введите число, например **1** или **999**  
   (система создаст участок автоматически если его нет)
3. **Загрузите любое фото** (JPG/PNG) - это может быть любая картинка для теста
4. **Введите голоса** для каждого кандидата (появятся поля после выбора выборов)

**Пример голосов:**
- Кандидат 1: 450
- Кандидат 2: 320
- Кандидат 3: 180

5. **Нажмите "Загрузить протокол"**
